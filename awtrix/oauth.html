Connexion Instagram

Configure d’abord l’identifiant Instagram, le secret personnel et l’URI de retour dans les paramètres de TasmostaInstagram sur l’horloge.

Ajoute ce lien à tes favoris, puis exécute-le lorsque tu es sur la page web de ton horloge :

Connecter Instagram

Si ton navigateur ne permet pas les favoris JavaScript, colle le code ci-dessous dans sa console sur la page AWTRIX. Il crée une demande liée à cette horloge, puis ouvre Instagram.

Ce fichier ne contient aucun identifiant secret. N’exécute ce code que sur ton horloge et sur un réseau de confiance.

Copie cette URL complète dans Apps → TasmostaInstagram → ⚙ → URL de retour Instagram sur ton horloge, puis enregistre. Le script vérifiera la demande avant d’obtenir le jeton.

Cette URL contient un code temporaire : ne la partage pas. En cas de refus, l’horloge expliquera qu’une nouvelle connexion est nécessaire.
